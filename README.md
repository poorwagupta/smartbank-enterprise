SmartBank Enterprise
Enterprise Banking Fraud Detection Platform built using Java 21, Spring Boot 3.5.7 and PostgreSQL.

Technology Stack
Java 21
Spring Boot 3.5.7
PostgreSQL 16
Maven
Spring Data JPA
Swagger OpenAPI
Lombok
Features
Create Transaction API
Retrieve Transaction API
PostgreSQL Integration
Swagger Documentation
Validation Framework
Security Configuration
Run
mvn clean install
mvn spring-boot:run
Swagger
http://localhost:8080/swagger-ui/index.html
